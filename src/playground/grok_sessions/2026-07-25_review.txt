### Speed

- **Q4 (Playwright)** is the bottleneck.
  - Reuse a single browser context across years or even across sources that share the same theme (where safe).
  - Prefer listing-page dates; the detail-page path is already opt-in / sources.yaml-driven and correctly expensive.
  - `--fallback-to-visible` / `--show-browser` is necessary for some Cloudflare sites; keep it opt-in.
  - Consider Playwright’s `channel="chrome"` + persistent context or a small pool of headed browsers if you have a display.

- **HTTP scrapers (InvestorRoom, Notified)** are already fast.
  - Parallelize independent sources (or even pages of the same source) with `concurrent.futures` or `asyncio` + a per-domain rate limiter.
  - Keep the global politeness rule (10–30 s between requests to the same host).

- **Orchestration**
  `scrape_all.py` currently runs sequentially. Add a controlled concurrency flag (default 1–2) so a full run finishes in minutes rather than hours while still respecting politeness.

- **Caching**
  Optional on-disk cache of rendered listing HTML (keyed by slug+year+hash of URL) would make re-runs and debugging much cheaper.
